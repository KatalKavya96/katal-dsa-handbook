## How every topic runs

1. **Theory with counter-questions** (interviewer mode).
2. **Foundational problems** in Python **and** Java. Before code: restate, hand-work an example, list edge cases, state approach and complexity.
3. **Pattern recognition** on unseen problems ("nodes? edges? query?" before naming an algorithm).
4. **CP grind**: CF and CodeChef problems ~100 to 300 above current rating, timed, then upsolve.

In parallel: rated contests on LeetCode, Codeforces and CodeChef, plus the LeetCode daily, all brought back for upsolving.
